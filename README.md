# توصيل العاشر | منصة التوصيل الذكية

منصة إلكترونية متكاملة لخدمة التوصيل داخل **مدينة العاشر من رمضان فقط**.

## المميزات

### 👤 العميل
- إنشاء حساب وتسجيل دخول
- إنشاء طلب توصيل مع تحديد المواقع على الخريطة
- متابعة الطلب بـ Timeline واضح
- تتبع المندوب على الخريطة (بيانات تجريبية)
- سجل الطلبات (جارية / مكتملة / ملغاة)
- تقييم المندوب بالنجوم
- إشعارات داخلية
- إلغاء الطلب

### 🏍️ المندوب
- تفعيل/إيقاف حالة "متصل"
- عرض الطلبات المتاحة وقبولها/رفضها
- تنفيذ مراحل الطلب خطوة بخطوة
- إحصائيات الأرباح والتقييم

### 🛠️ مدير النظام
- لوحة إحصائيات شاملة
- إدارة الطلبات (قبول / رفض / تعيين مندوب)
- إدارة العملاء والمندوبين (إيقاف/تفعيل)
- إدارة مناطق التغطية داخل العاشر من رمضان، وتعيين منطقة لكل مندوب
- إنشاء حسابات مديرين جدد من داخل لوحة التحكم
- خريطة حية للمندوبين المتصلين والطلبات
- بحث وفلترة

### 📦 دورة حياة الطلب (مندوب)
- قبول الطلب → استلام الشحنة → التوجه للتسليم → تسليم الطلب (مع إمكانية رفع صورة إثبات تسليم لو المستلم مش موجود)

### 👤 الملف الشخصي (عميل ومندوب)
- صورة شخصية، نبذة تعريفية، عنوان، ورقم هاتف
- للمندوب: تخصص/نوع المركبة، ومنطقة العمل، والتقييم

## ⚠️ قبل التشغيل: إعداد قاعدة البيانات المشتركة (مهم)

التطبيق بقى يستخدم Firebase Firestore كقاعدة بيانات واحدة مشتركة بين كل الأجهزة،
بدل التخزين المحلي في كل متصفح لوحده. لازم تعمل الخطوات دي مرة واحدة بس:

1. افتح ملف `firebase-config.js` واتبع التعليمات المكتوبة جواه (إنشاء مشروع
   Firebase مجاني ولصق بياناته في الملف).
2. بعد ما تحط البيانات، ارفع كل ملفات المشروع مع بعض على أي استضافة (Netlify /
   Vercel / GitHub Pages)، وافتح نفس الرابط من أي جهاز — هيشوفوا كلهم نفس
   البيانات والحسابات.
3. أي حساب (عميل / مندوب / مدير) يتعمل من أي جهاز هيظهر تلقائياً في كل
   الأجهزة التانية، لأنهم كلهم بيتكلموا مع نفس قاعدة البيانات.

من غير الخطوة دي التطبيق مش هيشتغل (هيظهر لك رسالة توضح إن الإعدادات ناقصة).

## التشغيل

1. افتح ملف `index.html` في متصفح حديث (Chrome / Edge / Firefox).
2. أو استخدم خادم محلي:
   ```bash
   npx serve .
   # أو
   python -m http.server 8080
   ```

## تحويل إلى تطبيق APK (Android)

المشروع جاهز كـ **PWA**. لتحويله إلى APK:

### الطريقة الأسهل (موصى بها):
1. ارفع المجلد على أي استضافة (Netlify / Vercel / GitHub Pages).
2. استخدم [PWA Builder](https://www.pwabuilder.com/) → أدخل الرابط → Generate → Android Package.

### باستخدام Capacitor (للمطورين):
```bash
npm init @capacitor/app
# انسخ ملفات المشروع إلى مجلد www
npx cap add android
npx cap sync
npx cap open android
# ثم Build APK من Android Studio
```

### باستخدام Bubblewrap (Google):
```bash
npm i -g @bubblewrap/cli
bubblewrap init --manifest https://your-domain.com/manifest.json
bubblewrap build
```
